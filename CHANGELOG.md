# Changelog

## 2.0.0 — Intent-Driven Master

- Added Markdown intent ingestion as the canonical low-friction project bootstrap path.
- Added owner-controlled `intake/` inbox and event-style watcher.
- Added `repoctl ingest`, `discover-intents` and `reconcile-intake`.
- Added normalized `INTENT_CONTRACT.json`, architecture proposal, bootstrap spec, decisions report and work package generation.
- Added deterministic scaffold profiles for Generic, Data Science, API, CLI, Web App, Library, Research and Infrastructure projects.
- Added automatic local scope contracts from normalized intent while preserving GREENFIELD state until real product content exists.
- Added content-addressed change detection: changed intents require explicit re-ingestion.
- Preserved the 19-point governance model and `CORE_CONTRACT != TOOL_ADAPTER` invariant.
- Intake may scaffold architecture but may not automatically implement product code.

## 1.0.0 — Governance Kernel

- Initial MDA governance kernel, adapters, 19-point model, repoctl, local scope contracts, audit chain, scheduled governance and deterministic validation.
