# Intent Inbox

This directory is the lowest-friction entrypoint to the governed repository.

1. Copy `OBJECTIVE_TEMPLATE.md` to a new Markdown file.
2. Write the vision, objective and any known constraints/deliverables/acceptance criteria.
3. Run `python .scripts/repoctl.py reconcile-intake`.
4. The repository normalizes the file, produces an architecture proposal/spec/work package, declares profile-based scopes and generates local `AGENTS.md` contracts.
5. No product code is generated by intake. Product implementation starts only through governed tasks.

Files under `intake/` are treated as owner-authored architecture intent. Elsewhere in the repository, a Markdown file is auto-discoverable only when it contains `MDA-Intent: true`, or it can be ingested explicitly with `repoctl ingest <path>`.
