# Repository State Machine

Repository state: `GREENFIELD -> BROWNFIELD`; `MIGRATING` is explicit when importing an existing project.

Capability state: `ABSENT -> DECLARED -> CONFIGURED -> ENABLED -> ENFORCED`; `QUARANTINED` and `DEPRECATED` are controlled side states.

Maturity: `M0_SEED -> M1_GUARDED -> M2_GOVERNED -> M3_SHADOW -> M4_FEDERATED -> M5_ECONOMIC`. Promotion never happens automatically.
