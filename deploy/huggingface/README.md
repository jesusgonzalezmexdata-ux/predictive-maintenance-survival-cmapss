# Condition-based maintenance

With a failure ten times more expensive than a preventive job, a survival model that reads each engine's recent condition decides when to intervene, and is compared with replacing the whole fleet by age.

**Result:** −40 % maintenance cost against age replacement (NASA C-MAPSS FD001, 100 engines, out of fold).

- Source code and evidence: [predictive-maintenance-survival-cmapss](https://github.com/jesusgonzalezmexdata-ux/predictive-maintenance-survival-cmapss)
