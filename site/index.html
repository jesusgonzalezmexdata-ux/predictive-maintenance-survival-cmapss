Which engines should be serviced now?

With a failure ten times more expensive than a preventive job, a survival model that reads each engine's recent condition decides when to intervene, and is compared with replacing the whole fleet by age.

How the decision was made

  1. Survival table with right-censoring and engines grouped in every split.
  2. Landmark model: only the last 20 cycles up to each inspection, never the future.
  3. Renewal-reward backtest of four policies, threshold tuned by inner cross-validation.
  4. Confidence intervals by engine bootstrap and a calibration check.

What it does not claim

  • Data simulated by NASA; not a production or aeronautical system.
  • One operating regime and one failure mode (FD001).
  • Costs are illustrative.
